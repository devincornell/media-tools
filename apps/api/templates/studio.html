       Studio guide
      
                
      
            
      
                
      The studio edits ffmpeg filtergraphs as boxes and wires. Everything you see maps one-to-one onto an ffmpeg command,
                    shown live in the ffmpeg tab at the bottom, so you can learn ffmpeg here or paste what you already know.
      
                
      How the pieces map to ffmpeg
      
                
      
                    
      In the studioIn ffmpeg
      
                    
                        
      Input nodeone -i FILE. Its pads v and a are the streams [0:v] and [0:a]. The file is chosen when you run the graph; options like -ss/-t trim it.
      
                        
      Filter nodeone filter with its options, e.g. scale=w=iw/2:h=-2. Every option ffmpeg has is listed, with its default and range.
      
                        
      Pads (dots)a filter's inputs (left) and outputs (right). overlay has two inputs (main, overlay); split has as many outputs as its outputs option.  video,  audio.
      
                        
      Link (wire)a link label like [scale1]. A straight run of one-in/one-out filters is written as a chain with commas: scale=...,hflip.
      
                        
      Output nodeone output file: each connected pad is a -map, its options are output options (-c:v libx264 -crf 20).
      
                        
      Saved graph nodeanother graph from your library, copied in when the graph runs. Change the saved graph and every graph using it changes too.
      
                        
       Parameteran option value lifted to the whole graph, e.g. the w of a scale as width. Its default is used unless you change it in the Run dialog, or on the node when the graph is used inside another graph. One parameter can drive several options.
      
                          
                
      
                
      Making a graph
      
                
        
                    
      1. Start from an example (left, Examples), import an ffmpeg command, or press New: you get an input wired straight to an output.
        2. 
                    
      2. Add filters: drag one from the left, press Tab, or select a wire and use Insert filter to put one in between.
        3. 
                    
      3. Connect by dragging from a dot to a dot of the same color. Dragging from a connected input dot picks the wire up again.
        4. 
                    
      4. Configure: select a node; the panel on the right lists its options and shows what each pad is connected to and under which label.
                        Click  next to an option to make it a graph parameter; with nothing selected, the panel lists the graph's parameters.
        5. 
                    
      5. Check the Problems tab: unconnected pads, wrong types, unknown options. The Run button works once there are none.
        6. 
                    
      6. Save it to the library with a name and description. Saved graphs can be opened, run, or added as a single node to other graphs.
        7. 
                    
      7. Run: pick a file per input (or many files for one input to process a batch) and where outputs go. Progress and logs appear under Runs.
        8. 
                
      
                
      ffmpeg rules worth knowing
      
                
        
                    
      • A filter output can only feed one place. If you wire one output to several inputs, the studio adds a split (or asplit) for you.
        • 
                    
      • Filters that combine pictures (overlay, hstack, blend) usually need inputs of compatible size: scale them first.
        • 
                    
      • Expressions use ffmpeg variables: iw/ih input size, ow/oh output size, t time in seconds, n frame number. Commas and colons inside values are escaped for you.
        • 
                    
      • Filters with a timeline badge accept enable, e.g. between(t,2,5) to apply them only from 2 s to 5 s.
        • 
                    
      • Filters and options that read or write files on the server (e.g. movie, drawtext textfile) are disabled.
        •
